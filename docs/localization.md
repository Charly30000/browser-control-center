# Localization

The translation engine, configuration, language catalogs and generation instructions are documented in [src/localization/README.md](../src/localization/README.md).

Author messages in `src/localization/locales/<language>.json` and register each language in `src/localization/config.json`. Root `package.nls*.json` files are generated VS Code integration artifacts. README content remains separate from the catalogs.
